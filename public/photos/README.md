# Website photos

Drop your photos here with these exact names. The site uses them automatically
(until a file exists, a stock photo is shown instead).

| File name          | Where it appears                      | Best shape        |
|--------------------|---------------------------------------|-------------------|
| konstantina.jpg    | Home — "The story behind the mat"     | Portrait, 4:5     |
| events-1.jpg … events-4.jpg | Events page gallery          | Landscape, 3:2    |
| studio-1.jpg … studio-3.jpg | Studio page gallery          | Landscape, 4:3    |

Tips
- Resize to about 1600 px on the long side and keep each file under ~400 KB
  (squoosh.app is free and easy). Big phone photos (5–10 MB) make the site slow.
- Use lowercase names, `.jpg`, no spaces.
- Captions and descriptions (Greek + English) are in `src/data/photos.ts`.
  Add or remove entries there if you have more or fewer photos.
